# IMDb Trakt.tv & Letterboxd Buttons
Adds a row of chip-style buttons below the genre chips on IMDb title pages:

- **Letterboxd** (movies only, via IMDb ID)
- **Trakt** (movies and shows, via IMDb ID)
- **TMDB** (via IMDb ID)
- **Wikipedia (de)** (via IMDb ID, resolved through Wikidata)
- **JustWatch (DE)** (title search)
- **WerStreamt.es** (title search)

## Installation
You need to have a UserScript extension (e.g. Tampermonkey for Chrome, Violentmonkey or Greasemonkey for Firefox) installed to run this script.

[Install this UserScript](https://github.com/SecretUnicorn/IMDB-Chart-Trakt.tv-Button/raw/master/imdb_trakttv_button.user.js)
